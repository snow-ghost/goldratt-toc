# Теория ограничений Голдратта

Скилл `goldratt-toc` для поиска ограничений системы и выбора мер по увеличению её пропускной способности. Подходит для производства, услуг, разработки, проектов и продаж.

Скилл помогает определить цель и границы системы, проверить гипотезу об узком месте по данным, лучше использовать текущую мощность, согласовать работу остальных этапов и оценить необходимость расширения. Для предложенного изменения задаёт измеримую проверку эффекта и условия повторной диагностики.

## Состав

- [SKILL.md](SKILL.md) — инструкции и пять фокусирующих шагов TOC.
- [Диагностика](references/diagnosis.md) — данные, расчёт нагрузки и проверка гипотез.
- [Инструменты улучшения](references/interventions.md) — Drum–Buffer–Rope, Critical Chain, Thinking Processes и Throughput Accounting.
- [Источники](references/sources.md) — ссылки, ограничения и границы прикладной адаптации.

## Использование

Поместите папку репозитория в каталог скиллов вашего агента. Например, для стандартной установки Codex:

```bash
git clone https://github.com/snow-ghost/goldratt-toc.git ~/.codex/skills/goldratt-toc
```

Если этот путь уже занят, используйте существующую установку или выберите другой путь. В новой сессии вызовите:

```text
$goldratt-toc Найди узкое место в нашем процессе.
Вот этапы, объёмы, очереди и сроки: …
Предложи план улучшения и первый проверяемый эксперимент.
```

При нехватке данных скилл формулирует предварительный диагноз и план измерений. Рост локальной мощности не считается автоматически ростом результата всей системы.

Методическая основа — открытые материалы Goldratt Research Labs, TOC Institute, TOCICO и других источников, перечисленных в справочнике. Протокол диагностики и примеры применения включают явно обозначенную прикладную адаптацию.
